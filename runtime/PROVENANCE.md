# Continuity adapter

`continuity/drawing.py` comes from the existing
`/Users/ubl-ops/powerfarm-continuity/continuity/drawing.py` supplied by the operator.
The original compiler is preserved there. The adapter adds an optional state type,
keeping the original default, and dotted field lookup for conditional branches.
`run_graph.py` binds named
valves to Antenna's existing bounded Rust capabilities using LangGraph interrupts.

The original `pyproject.toml` and `uv.lock` are retained. Resolved engine versions:
LangGraph 1.2.11 and langgraph-checkpoint-sqlite 3.1.1.

The Temporal-oriented Continuity v2 archive is preserved separately. This adapter
uses the JSON graph compiler that already executes graphs; it does not claim the
v2 Temporal worker is implemented.
